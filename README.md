# Game Catalog Project

Backend katalog game yang ditulis menggunakan Go. Project ini menyediakan struktur dasar model game, handler HTTP, middleware logging, dan static serving.

## Struktur

- `Game_Catalog_Project/main.go` — entry point server
- `configs/` — konfigurasi aplikasi/database
- `models/` — model data game
- `handlers/` — handler katalog dan static file
- `middlewares/` — middleware logging
- `utils/` — helper aplikasi

## Menjalankan

Membutuhkan Go sesuai versi pada `go.mod`.

```bash
cd Game_Catalog_Project
go run .
``

## Status

Project pembelajaran backend Go untuk latihan routing, handler, model, database/configuration, dan middleware.
